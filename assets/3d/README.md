# 3D character asset

`jordan-idle.glb` is the full-body, textured and rigged "Idle standing - Jordan" character from [Innerscene's 3D parts library](https://www.innerscene.com/tools/library/3d-parts/idle-standing-jordan-3d-person-animated). The source listing identifies it as public domain under CC0, adapted from MakeHuman/MPFB CC0 assets. It includes the six-second `Idle_Standing` animation.

The embedded PNG textures were downsampled to a maximum dimension of 1024 pixels for web delivery. The model, rig and animation were retained.
